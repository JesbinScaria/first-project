\## 📌 Project Overview



This is my first practical project based on Git and DevOps. The main aim of this project is to learn version control, repository management, and basic development workflows.



This project demonstrates how to create, manage, track, and upload project files using Git, GitHub, and Gitea.

\## 💻 Basic Git Commands



| Command | Purpose |

|---|---|

| `git init` | Initialize repository |

| `git status` | Check file status |

| `git add .` | Add project files |

| `git commit -m "message"` | Save changes |

| `git log` | View commit history |

| `git push` | Upload changes |

| `git pull` | Download changes |

| `git clone` | Clone a repository |
